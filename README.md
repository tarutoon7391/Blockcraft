# BlockCraft

マイクラ風ボクセルゲームのマルチプレイ版。同じURLを開いた全員が、同じワールドで一緒に遊べる。

## 遊べること

- 地形生成（バイオーム・洞窟・鉱石）、ブロックの破壊と設置、インベントリ、クラフト、昼夜
- マルチプレイ（ブロック・アイテム・時刻・チャットを同期）、プレイヤー同士の戦闘
- モブ: 昼は動物（豚・牛・鶏）、夜はゾンビ
- かまど、鉄・金・ダイヤ、ツール5種（ツルハシ・斧・シャベル・剣・クワ）× 5素材
- 農業: クワで耕す → 種を植える → 育ったら収穫 → パン
- ベッド（復活地点・全員で寝ると、夜なら朝に、昼なら夜になる）、防具（鉄・金・ダイヤ）、盾、ハサミ、バケツ、時計
- 建材: 羊毛、鉱石ブロック、石レンガ、ガラス、レンガ。苗木を植えると木が育つ
- チェスト（中身はサーバー保存）、卵、ケーキ、にんじん、じゃがいも
- 弓と矢、クモ、スケルトン、骨粉
- タルボム（爆発する敵）、カスミ（瞬間移動する敵）、爆薬、ワープ玉、導きの目
- 松明: 石炭か木炭＋棒で4本。床や壁に置くと周りを照らす（夜・洞窟）。光が届く所にはゾンビが湧かない（湧きつぶし）。木炭は原木をかまどで焼くとできる

## 建材（第8弾）

- 飾りブロック: 滑らかな石・ひび割れた石レンガ・磨いた深石・滑らかな砂岩（かまどで焼く）、苔むした石レンガ・苔むした丸石（＋葉）、模様入りの石レンガ・砂岩（ハーフ2枚）、漆喰、瓦、畳、障子、干し草の俵、寄木の床、雪のレンガ、灯晶ガラス（光る）、深石のタイル、金の装飾レンガ、市松模様のタイル、鉄の床板、提灯（光る）
- 形のあるブロック（ID 1000 以上。チャンクは Uint16Array）: 23素材のハーフ・階段（上下・4方向）、塀、木の柵、羊毛のカーペット・畳のござ、木の扉・鉄の扉、跳ね上げ戸、柵の門、はしご、板ガラス、鉄格子
  - 形は `shapeBoxes` が返す箱の集まり。当たり判定・狙い・見た目・アイコンすべてこれを使う。柵・塀・閉じた門の当たり判定は高さ1.5
  - ハーフ・階段は向いている方向と狙った高さで向きと上下が決まる。同じ素材のハーフを重ねると1ブロックに戻る
  - 地面にいる時は半ブロックまでの段差を歩くだけで登る。はしごは前に進むかジャンプで登る
  - 扉・跳ね上げ戸・柵の門は右クリックで開け閉め（何か持っていても開く。置く時はスニーク）。鉄の扉も手で開く
- かまど: 中身はサーバーが持ち（`furnaces`）、開いている間はその人のブラウザが、閉じている間はサーバーが1秒ずつ焼く。壊すと中身を落とす。焼ける物と燃料の表はブラウザの `SMELT`・`FUEL` とサーバーで同じ物を持っている（変える時は両方）

## 水（第9弾）

- マイクラと同じ考え方で流れる。水源（5）から横に7マスまで広がり（1801〜1807、数字が大きいほど浅い）、下が空いていれば落ちる（1808）。水源が無くなると引いていく。水源2つに挟まれて下が地面か水源のマスは水源になる
- 計算するのは近くのブロックを変えた本人のブラウザだけ（`updateWater`、0.25秒ごとに最大300マス）。結果は sets で全員に配る。自然の海や湖は、誰かが近くを変えるまで動かない
- 流れている水の中にいると浅い方へ押し流される。バケツで汲めるのは水源だけ

## 世界（ディメンション）

地上のほかに別世界が2つある。地底は地形と鉱石まで、虚空はまだ仮の地形だけ。

- プレイヤー・モブ・落ちているアイテムは「今いる世界」を持ち、同じ世界の人にだけ見える
- ブロックの変更は1つの表で持ち、別世界の分はキーの頭に `1:` `2:` を付けて区別する（地上は今まで通り）
- 地底への門: 地上の一番下（y=1）の岩盤を爆薬で吹き飛ばすと、10% で割れて岩盤ブロックを落とす。それを 5×5 の輪（真ん中 3×3 は空ける。四隅は無くてよい）に並べ、真ん中で爆薬を爆発させると輪の内側が門になる。この時の爆発は見た目だけ。門の上に約1.2秒立つと地上⇔地底を移動し、着いた先に門が無ければ帰りの門ができる
- 地底: 深石でできた暗い地下世界。光苔・光るキノコ（大きいキノコの森もある）・灯晶石が光る。低い所は地底湖、天井と床に鍾乳石・石筍
  - 鉱石（黒鉄鉱・紅炎石・虚晶石は空洞や水に面した所には出ない＝必ず地中）: 灯晶石（石のツルハシ。灯晶2〜3個 → 灯晶ランプ・松明）、黒鉄鉱（鉄。焼くと黒鉄インゴット）、紅炎石（ダイヤ。y14以下だけ。燃料にすると石炭の8倍）、虚晶石（黒鉄。遺跡の半径48ブロック以内だけ）
  - 装備: 黒鉄・紅炎・虚晶のツール5種と防具4部位。強さは ダイヤ < 黒鉄 < 紅炎 < 虚晶（剣 7/8/9/10、全身の防御 20/21/22/23）
  - 全身の効果: 紅炎=爆発ダメージ半分・殴った相手が3秒燃える（モブ 2/秒、プレイヤー 1/秒）。虚晶=落下ダメージなし・敵が10ブロックより近づかないと気づかない
  - 遺跡: 480ブロック四方の区画の半分ほどにだけある（場所は `ruinAt`、形は `ruinBlock`）。広間の床の高さは区画ごとに y=10〜23。25×25 の大広間（中は 21×21×10）と四方の短い通路（行き止まり）を厚い深石の殻で包んで地中に埋めてあり、洞窟からは見えない。真ん中に紋章石の台、柱4本、壁に紋章石の明かり。遺跡のブロックは硬く、鉄のツルハシ以上で回収できる
  - 遺跡の四隅のチェスト: 地形の一部なのでサーバーは edits ではなく計算（`isRuinChest`）で見分け、最初に開けた（または壊した）時に中身を決める（灯晶・黒鉄・パンは必ず、紅炎・虚晶・ダイヤ・金・爆薬・導きの目・骨は確率）
  - おかかっぱ（遺跡のボス）: 誰かが広間に近づくと（中心から22ブロック以内）、真ん中の台の上に出る。体力300、高さ3.5×幅2。攻撃は防具の効き目を半分にする。近いと殴る（10、1.5秒おき。体力が半分を切ると1.1秒おきで足も速くなる）。離れると0.9秒溜めて岩を投げる（4〜5秒おき、体力が半分を切ると2.5〜3.5秒おき）。岩は投げた瞬間の相手の位置へまっすぐ飛び、何かに当たると爆発する（最大13、ブロックは壊さない）。ほとんど吹き飛ばず、爆薬のダメージは1回10まで。近くに誰もいなくなると消え、また近づくと体力満タンで出る
  - 倒すと: おかかっぱの核と虚晶1〜2個を落とし、台の真ん中3×3が虚空の門になる。その遺跡では二度と出ない（サーバーの `cleared` に保存）
  - 虚空の門: 上に約1.2秒立つと地底⇔虚空。虚空では同じ座標に足場（7×7）と帰りの門ができる。虚空の門は壊せない
  - 特別装備（核が1つ要る）: 紅炎の大剣（12、振りが遅い、当てると燃える）、噴火の槌（右クリックで周り5ブロックに8＋吹き飛ばし、8秒ごと）、紅炎の弓（当たると小さく爆発する矢）、虚晶の刃（11、右クリックで前へ最大5ブロック瞬間移動、5秒ごと）、虚晶の杖（右クリックで光の弾、7）、虚無の外套（虚晶の胴と同じ守り＋2割で攻撃を無効）
  - 導きの目: 地底で右クリックすると一番近い遺跡の方へ飛んでいき、8割は落ちてきて拾える。地上と虚空では何も起きない（減らない）
- 岩盤のさらに下（y=0）は深層岩。何をしても壊れず、置くこともできない
- 虚空の入口はまだ無い。チャットで `/dim 0`（地上）`/dim 1`（地底）`/dim 2`（虚空）と打っても移れる
- 地底・虚空で倒れると地上へ戻り、地上のベッド（無ければスタート地点）で復活する。地上以外のベッドは復活地点にできない
- 地形は `public/index.html` の `genDeep` / `genVoid`、空の色などは `DIMS` で決めている

## 構成

| ファイル | 役割 |
|---|---|
| `server.js` | 画面の配信と、WebSocket での同期（Node.js + ws） |
| `public/index.html` | ゲーム本体（描画・操作・地形生成はすべてブラウザ側） |

サーバーは地形データを持たない。全員に同じシード値を配り、各ブラウザが同じ地形を生成する。
サーバーが持つのは「シード値・変更されたブロック・時刻・落ちているアイテム・各プレイヤーの位置」だけ。

モブ（ゾンビ・動物）も同じ理由で、動かすのは「一番近いプレイヤーのブラウザ」。その位置をサーバー経由で全員に配る。
モブの体力・生死・ドロップ、作物の成長はサーバーが管理する。プレイヤーの体力と持ち物は各自のブラウザが持つ。

## ローカルで動かす

```
npm install
npm start
```

`http://localhost:3000` を開く。タブを2つ開けば2人プレイの確認ができる。

## Railway に置く

1. Railway で「Deploy from GitHub repo」からこのリポジトリを選ぶ（起動コマンドは `npm start` が自動で使われる）
2. Settings → Networking で公開ドメインを発行する
3. ワールドを残すために Volume を追加して `/data` に割り当て、環境変数 `DATA_DIR=/data` を設定する

3 をやらないと、再デプロイのたびにワールドが新しく作り直される。

## 保存されるもの

- **ワールド（サーバー側）**: シード値、変更されたブロック、チェストの中身、時刻。20秒ごとと終了時に `DATA_DIR/world.json` へ保存
- **持ち物・位置・体力（ブラウザ側）**: 各プレイヤーのブラウザの localStorage に、ワールド×名前ごとに保存。別のブラウザや端末、別の名前で入ると空から始まる

ワールドを作り直したい時は `world.json` を消して再起動する。

## 接続まわり

- **自動再接続**: 再デプロイや回線断で切れたら、`/health` が返るのを待ってページを読み直し、同じ名前で自動で入り直す
- **二重ログイン**: 同じブラウザから同じ名前で入り直すと古い方を切る（別タブ・切れたまま残った接続）。別の人と名前がかぶったら「名前(2)」になる
- **接続確認**: サーバーが20秒ごとに ping を送り、返事が無い接続は切る（いない人が立ったまま残らない）
- **連打制限**: `server.js` の `RATE` に種類ごとの上限がある（チャットは制限なし）。新しいメッセージの種類を足して回数が多い時はここにも足す
