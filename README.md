# BlockCraft

マイクラ風ボクセルゲームのマルチプレイ版。同じURLを開いた全員が、同じワールドで一緒に遊べる。

## 構成

| ファイル | 役割 |
|---|---|
| `server.js` | 画面の配信と、WebSocket での同期（Node.js + ws） |
| `public/index.html` | ゲーム本体（描画・操作・地形生成はすべてブラウザ側） |

サーバーは地形データを持たない。全員に同じシード値を配り、各ブラウザが同じ地形を生成する。
サーバーが持つのは「シード値・変更されたブロック・時刻・落ちているアイテム・各プレイヤーの位置」だけ。

## ローカルで動かす

```
npm install
npm start
```

`http://localhost:3000` を開く。タブを2つ開けば2人プレイの確認ができる。

## Railway に置く

1. Railway で「Deploy from GitHub repo」からこのリポジトリを選ぶ（起動コマンドは `npm start` が自動で使われる）
2. Settings → Networking で公開ドメインを発行する
3. ワールドを残すために Volume を追加して `/data` に割り当て、環境変数 `DATA_DIR=/data` を設定する

3 をやらないと、再デプロイのたびにワールドが新しく作り直される。

## 保存されるもの

- **ワールド（サーバー側）**: シード値、変更されたブロック、時刻。20秒ごとと終了時に `DATA_DIR/world.json` へ保存
- **持ち物・位置・体力（ブラウザ側）**: 各プレイヤーのブラウザの localStorage。別のブラウザや端末で入ると空から始まる

ワールドを作り直したい時は `world.json` を消して再起動する。
